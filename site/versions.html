Back to the hub.

Part IV of this book covers software that changes faster than a book can be reprinted. This page carries the current state and a dated record of what has moved, so that a chapter written in 2026 stays usable.

Where this page and the printed book disagree, this page is current and the book records what was true when it was checked. Checked is the date someone last read the upstream source, not the date the version was released: a row checked long ago is a row you should verify yourself.

How these were checked

Every value below was read from the project's own repository, release page or licence file. No summary site, package-tracker or blog post was used, because those are exactly the sources that go stale without saying so. The Source column is the page actually read, so you can repeat the check rather than trust it.

Where a value could not be found, the row says not found and where the search was made. Where two primary sources disagree, both are recorded.

Contradicts the book

The four findings below are not page corrections. They are chapter edits, listed here so they are not lost among values that merely moved. The Version in the book and Licence in the book columns above are deliberately left as the book printed them.

Three concern Chapter 13 and one concerns Chapter 15, which repeats two of the same errors in a different form. Two of the four are changes upstream and appear in the changelog; the other two are wording that has been wrong since the book was written, and do not.

This affects the code only. The weights are governed by a separate Terms of Use, which did not change: the same commit edited that file only to update its cross-reference to the code licence, five lines, leaving the restriction itself untouched.

2. The weights are no longer obtained by request

The book describes the weights as available by request. That was accurate when written and is not any more: the request form was removed on 2026-07-23 and replaced with a public download URL. The non-commercial restriction is unaffected — use is still governed by the Terms of Use — but nothing now gates the download itself.

The book says By request, non-commercial organisations only
Was “To request access … please complete this form. Access will be granted at Google DeepMind's sole discretion … within 2–3 business days. You may only use AlphaFold 3 model parameters if received directly from Google.”
Is now “You can download the AlphaFold 3 model parameters from https://storage.googleapis.com/alphafold3/af3.bin.zst. Use is subject to these terms of use.” A request for that URL returns 200 OK with no authentication, checked 2026-09-18.
Changed2026-07-23
Read at commit dd1a7bad, “Update the instructions on how to obtain AlphaFold 3 weights”, which edited README.md and docs/installation.md
AffectsChapter 13

The half of the book's sentence that still holds is the important half. Who may use the weights has not changed; only how you get hold of them.

3. The weights are restricted by organisation type and by activity

Chapter 13 states that AlphaFold 3's weights are restricted by organisation type rather than by activity. The first half is right and is the part most readers get wrong — but “rather than” is too strong, because the policy restricts on both axes at once.

Organisation type “only non-commercial organizations … may use the AlphaFold 3 Assets … The AlphaFold 3 Assets are not available for any other types of organization, even if conducting non-commercial work.”
Activity The same clause prohibits use “in connection with any commercial activities”, and permits a non-commercial organisation to use the assets for “their non-commercial activities”.
Read at WEIGHTS_PROHIBITED_USE_POLICY.md, clause 1 and sub-clauses 1.1–1.3
Checked2026-09-18
AffectsChapter 13

This one did not move. The wording has stood since the initial release on 2024-11-11, so it is a reading to correct rather than a change to record, and it has no changelog row below. The chapter's point survives, but for a more precise reason than it gives: the organisation test binds independently — a commercial organisation is excluded even when the work is non-commercial — not because activity is irrelevant. Both tests must be met.

4. Chapter 15 repeats both weights errors in Table 15.1

Table 15.1 lists AlphaFold 3 as “Gated; weights by request, non-commercial organisations”, and the sentence above it repeats that the weights are available by request. Findings 2 and 3 apply again, in a different place.

“Gated” and “by request” No longer true as of 2026-07-23. The request form was removed and the weights are a public download; the URL returns 200 OK with no authentication. Nothing gates the file. Same correction as finding 2, and the same changelog row covers it.
“non-commercial organisations” Incomplete in the same way as finding 3. The organisation test is necessary but not sufficient: a non-commercial organisation is still confined to its non-commercial activities. Not a change — this has been the wording since 2024-11-11.
Read at commit dd1a7bad and WEIGHTS_PROHIBITED_USE_POLICY.md
Checked2026-09-18
AffectsChapter 15, Table 15.1 and the sentence above it

Finding 1 bears on this table directly. Table 15.1 sets AlphaFold 3's row against Apache 2.0 and MIT rows for the other models, and AlphaFold 3's code is now Apache 2.0 like the rest — only the weights are restricted. The contrast the table needs survives, because Apache 2.0 code is no use without weights you cannot obtain.
